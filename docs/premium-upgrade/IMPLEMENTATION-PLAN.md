## 1. Architectural Foundation & Non-Negotiable Boundaries

### Current Stack & Components
* **Framework & Tooling:** React 19.0.1, TypeScript 7.0.2, Vite 8.3.0, Tailwind CSS 4.3.3, Lucide React 0.546.0.
* **State Management:** Single central store in `src/context/PlannerContext.tsx`. No secondary stores or split state.
* **Data Persistence:** `src/utils/storageCoordinator.ts` provides multi-phase atomic writes to `localStorage`, readback verification, quarantine of unreadable data blocks, and tab synchronization via `BroadcastChannel` / storage events.
* **Backup & Migration:** `src/utils/backupValidator.ts` validates 15 modules and user preferences, provides pre-restore safety snapshots, and rollbacks.
* **Module Registry:** `src/utils/moduleRegistry.ts` acts as the single source of truth for tool visibility, favorites, and categories.
* **Accessibility Infrastructure:** `src/components/ui/Modal.tsx` and `useDialogAccessibility` enforce focus containment, Escape dismissal, and return of focus to invoking controls.
* **Dual-Delivery Targets:**
  1. **Hosted / PWA Edition:** Served over HTTP/HTTPS with offline caching via `public/sw.js`.
  2. **Standalone Offline Edition:** Single standalone HTML file `dist/Our-Life-Planner-Offline.html` generated by `scripts/build-standalone.mjs`, containing inlined CSS, JS, and SVG assets with zero external network calls.

### Preservation Rules
1. **Existing Records & Types:** Stored record schemas (`TaskItem`, `RoutineItem`, `FinancialTransaction`, `HabitItem`, etc.) remain backward-compatible. Additions must be optional.
2. **Local Data Safety:** Never clear or reset user storage during upgrade. Testing must run against isolated browser profiles and throwaway demo sessions.
3. **Stand-alone Bundle Integrity:** Standalone offline builder expects single bundled JS and CSS. Code-splitting must not emit unbundled external script tags into the standalone build.
4. **No CDN Dependencies:** All fonts, icons, charts, and textures must function completely offline.

## 3. Today Dashboard Composition (Priority 1)

### Visual Hierarchy & Above-the-Fold Balance (1280×720 & 1440×900)
Visual analysis of baseline screenshot `today-1280x720-light.png` reveals that the header greeting, yellow demo banner, 3-button utility bar, expansive overdue panel (~200px), and full-width week strip push actionable daily tasks and the day's schedule completely below the fold.

**Recomposed Layout:**
```text
+---------------------------------------------------------------------------------------------------+
| Sidebar (216-224px) | Top Bar (64px): Search | Quick Add | Saving Indicator | Profile             |
+---------------------+-----------------------------------------------------------------------------+
|                     | Today Heading & Context: "Wednesday, October 14" + Primary Action Button    |
|                     | Compact Alert Pill (Overdue count + "Review" action, expandable drawer)     |
|                     +-----------------------------------------------------------------------------+
|                     | [1. Featured Card]   | [2. Completed]     | [3. Needs Action]  | [4. Streak]   |
|                     | Commitments Today    | Done Today         | Overdue Items      | Weekly Rate   |
|                     | (Deep Navy #071A3A)  | (Crisp Card)       | (Crisp Card)       | (Crisp Card)  |
|                     +-------------------------------------------+---------------------------------+
|                     | Next Up & Selected Day Schedule (Wide)    | Supporting Habits / Trend       |
|                     | - Next urgent commitment                  | - Daily rhythm check-ins        |
|                     | - Time-blocked agenda items               | - Weekly completion mini-chart  |
|                     |                                           | - Compact Focus Timer card      |
|                     +-------------------------------------------+---------------------------------+
|                     | Enabled Modules Summary (Budget, Meals, Workouts) if toggled on in Settings |
+---------------------+-----------------------------------------------------------------------------+
```

### The 4 Today Metric Cards: Explicit Scopes & Formulas
1. **Featured Card — Commitments Today (Deep Navy / Accent Surface):**
   * *Formula:* Total eligible tasks with `dueDate === selectedDate` (or unscheduled tasks explicitly flagged for today) + routine occurrences active for `selectedDate`.
   * *Denominator Scope:* Selected day only. Non-duplicative, resets cleanly per date selection.
2. **Completed Today:**
   * *Formula:* Eligible commitments from card #1 where `status === 'completed'` or routine is marked completed for `selectedDate`.
   * *Scope:* Strict subset of metric #1. Empty denominator shows `0` (not NaN or 100%).
3. **Needs Attention:**
   * *Formula:* Tasks where `dueDate < currentDate` and `status !== 'completed'`.
   * *Scope:* Clearly labeled overdue scope ("X overdue across all dates"). Clicking opens task list filtered by overdue.
4. **Weekly Consistency:**
   * *Formula:* (Completed commitments in current calendar week) / (Total due commitments in current calendar week) × 100%. If Habits module is enabled, incorporates habit check-in rate.
   * *Scope:* Current calendar week (Monday–Sunday or Sunday–Saturday based on user setting).

## 4. Shared Tokens, Surfaces & Component Architecture

### Spacing & Grid System
* Base Spacing Scale: `4px` (micro), `8px` (compact), `12px` (standard control gap), `16px` (card interior padding), `24px` (section gutter), `32px` (page canvas padding).
* Card Geometry: Uniform `16px` border-radius (`rounded-2xl`), subtle border (`1px solid var(--border-color)`), soft elevation (`var(--shadow-card)`).

### Typography Scale
* Page Title: `26–28px` (font-bold, tracking-tight). Current page title moves into the page canvas.
* Section / Card Headers: `16–18px` (font-semibold).
* Metric Values: `32–38px` (font-extrabold, `tabular-nums` for stable width).
* Body Text: `14–15px` (`text-primary`, leading-normal).
* Secondary & Metadata: `12–13px` (`text-secondary` / `text-muted`).

### Button & Control Conventions
* Control Height: `40px` on desktop; `44px` minimum touch target on mobile/tablet viewports.
* Standard Tonal Variants:
  * Primary: Solid accent (`bg-accent text-white`).
  * Secondary / Tonal: Soft accent tint (`bg-accent-soft text-accent hover:bg-accent-soft-hover`).
  * Ghost / Tertiary: Subdued surface hover (`hover:bg-surface-muted text-secondary`).
* Keyboard Focus: 2px offset focus ring (`focus-visible:ring-2 focus-visible:ring-offset-2`).

## 5. Coordinated Accent & Theme Migration

### Semantic Variable Hierarchy
The design token system in `src/index.css` will be extended with role-based variables:
* Canvas & Surfaces: `--canvas`, `--surface`, `--surface-elevated`, `--surface-subtle`, `--surface-muted`.
* Typography: `--text-primary`, `--text-secondary`, `--text-muted`.
* Coordinated Accent Roles:
  * `--accent`: Primary active tint.
  * `--accent-hover`: 10% deeper interaction state.
  * `--accent-soft`: 10–15% light tint for chips, badges, tonal buttons.
  * `--accent-deep`: Dark saturated navy/accent for the featured summary card and timer.
  * `--focus-ring`: Accessible focus indicator.
  * `--chart-current`: Solid line/fill for active period.
  * `--chart-previous`: Dashed comparison series.

### Accent Palettes (Light & Dark Values)
1. **Teal (Familiar Legacy):** Accent `#087F83` / `#38D0C5`, Deep `#071A3A` / `#0B1220`. Preserved as fallback for existing settings.
2. **Ocean (Reference Direction):** Accent `#2754C5` / `#60A5FA`, Deep `#102B63` / `#0D1B3E`, Canvas `#F4F6F9` / `#0B1220`. Default for fresh profiles.
3. **Plum:** Accent `#7C3AED` / `#A78BFA`, Deep `#3B1366` / `#1F0B36`.
4. **Ember:** Accent `#C2410C` / `#FB923C`, Deep `#541C07` / `#2E1005`.

### Semantic Preservation
Warning (`#D97706`), Danger/Overdue (`#DC2626`), and Success (`#16A34A`) retain fixed distinct hues regardless of active accent.

## 6. Tasks Architecture: List, Board & Insights

### Board View Mapping
TasksView will provide a 3-way toggle: `List | Board | Insights`.
* Columns map directly to stored `TaskStatus`:
  1. **To Do:** `not_started`
  2. **In Progress:** `in_progress`
  3. **On Hold:** `on_hold`
  4. **Done:** `completed` (sets `completedAt` timestamp)
* Direct Manipulation (Drag & Drop):
  * Lifted card gets higher z-index and elevation shadow.
  * Origin slot displays ghost/placeholder outline.
  * Destination column displays tinted highlight border.
  * Pressing `Escape` cancels drag cleanly with zero state mutation.
* Keyboard & Touch Accessibility:
  * Every card provides a quick status change menu (`Move to...` dropdown) enabling 100% mouse-free workflow.

## 7. Visual Analytics & Chart Contracts

* **Data Integrity:** Charts will strictly consume real timestamps (`createdAt`, `completedAt`, `dueDate`). Missing timestamps will display explicit empty trends or data boundaries rather than simulated curves.
* **Throughput & Comparison:**
  * Active range: 7 Days | 30 Days | 90 Days.
  * Solid line represents current period daily completions; dashed line represents preceding period of equal length.
* **Accessible Inspection:**
  * Hover / focus displays vertical crosshair line and inspection tooltip (date, count, % delta).
  * Tabular text alternative provided for screen readers and keyboard users.
* **Stable Number Motion:** Brief transition (150–200ms) on real value changes. No arbitrary zero-resets on simple page navigation.

---

## 8. Focus Timer & Session Persistence

* **Shared Session Controller:** A single active session drives both the compact Today dashboard card and the full `FocusModal`.
* **Timestamp-Based Counting:** Store `startedAt`, `targetEndTime`, `remainingSecondsWhenPaused`, and `timerState` (`idle | running | paused | break`) in `localStorage`.
* **Resilience:** Navigating views, backgrounding the browser tab, or refreshing the page computes remaining time from `targetEndTime - Date.now()`, preventing timing drift or lost sessions.
* **Subtle Contour Texture:** Apply faint SVG contour lines exclusively to the dark focus card, matching `frame-012.png`.

---

## 9. Contextual Capture & Shared Drawer System

* **Contextual Quick Add:** Triggering Quick Add from within a specific tool (e.g., Tasks, Budget, Meals) pre-selects that module form while preserving global category tabs.
* **Reusable Drawer:** Extend `src/components/ui/ContextualDetailPanel.tsx` to handle task editing, calendar event inspection, and item details.
* **Scroll & Focus Preservation:** Closing the drawer restores focus to the triggering item and preserves existing table/board scroll position.
