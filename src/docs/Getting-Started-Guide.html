1. Quick Start in 3 Steps

1 Open the File

Double-click Our-Life-Planner-Offline.html in any modern browser (Edge, Chrome, Safari, Firefox). No internet connection or installation required.

2 Complete Setup

Follow the 2-minute Setup Wizard: enter your name, select light/dark theme, choose your week start day (Monday/Sunday), and pick your local currency.

3 Begin Daily Loop

Navigate to Today for your morning overview, add tasks via Quick Add (press Ctrl+K / Cmd+K), and focus with the built-in timer.

2. The Core Daily Momentum Loop

Our Life Planner is organized around a simple 4-step workflow to eliminate mental fatigue:

1. Capture (Brain Dump)

Quickly jot down unfinished thoughts, ideas, or to-dos into the Brain Dump or Quick Add modal without worrying about organization yet.

2. Schedule (Calendar & Tasks)

Assign tasks to dates and specific time blocks. The planner alerts you to schedule conflicts automatically so your day remains realistic.

3. Complete (Focus Mode)

Open Focus View (press F) to work on one task at a time with a gentle 25-minute focus timer and 5-minute restorative breaks.

4. Review (Weekly Review)

At the end of each week, run the Weekly Review helper to triage overdue items, celebrate completed goals, and set next week's priorities.

4. How Your Data Persists (Storage Architecture)

Our Life Planner saves all information directly into your browser's local origin database (localStorage) using atomic multi-phase verification.

  • 100% Private: No personal details, financial records, health data, or notes are ever transmitted to remote servers.
  • Device & Folder Boundaries: Each browser profile and file path maintains its own local storage space. If you relocate the HTML file to a new folder or switch to a new browser, your previous data remains in the original origin.
  • Upgrading & Moving Devices: Use the built-in JSON Backup & Restore feature to move your records seamlessly.

5. Backup, Restore & Upgrade Routine

How to Create a Backup
  1. Go to Settings > Data & Storage (or press Ctrl+B).
  2. Click Export JSON Backup.
  3. A dated JSON file (e.g. our-life-planner-backup-2026-10-13.json) downloads immediately to your computer.

Recommendation: Export a backup once a week or before updating browser versions.

How to Restore or Upgrade
  1. Open your new or relocated Our-Life-Planner-Offline.html.
  2. Open Settings > Backup & Restore.
  3. Click Choose File to Restore and select your saved backup JSON file.
  4. Confirm restore. All your tasks, habits, budgets, and logs are instantly loaded.

6. Device Compatibility & Phone Instructions

Desktop (Mac, Windows, Linux)

Works natively in Microsoft Edge, Google Chrome, Apple Safari, and Mozilla Firefox. Simply save the file to your Documents or Desktop folder and open it.

iOS (iPhone & iPad)

When accessing the web app version in Safari, tap the Share button and choose Add to Home Screen. This creates a full-screen app icon with persistent offline storage.

Android Phones & Tablets

Open the web version in Chrome, tap the menu (three dots), and select Install app or Add to Home screen for an app-like experience.
